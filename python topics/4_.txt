MODULE 4: FUNCTIONS
==============================

4.1 Function Definition
-----------------------
A function is a block of code used to perform a specific task.

Functions help in code reusability and modularity.

Syntax:
def function_name(parameters):
    # code
    return value

Example:
def add(a, b):
    return a + b

--------------------------------

4.2 Function Arguments
----------------------
Arguments are values passed to functions.

Types of arguments:
1. Positional arguments
2. Keyword arguments
3. Default arguments
4. Variable-length arguments (*args, **kwargs)

Example:
def greet(name="User"):
    print("Hello", name)

--------------------------------

4.3 Return Statement
--------------------
The return statement is used to send a value back from a function.

Example:
def square(x):
    return x * x

--------------------------------

4.4 Lambda Functions
--------------------
Lambda functions are small anonymous functions.

Syntax:
lambda arguments: expression

Example:
square = lambda x: x * x

--------------------------------

4.5 Recursion
-------------
A function calling itself is called recursion.

Example:
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n-1)

--------------------------------

4.6 Built-in Functions
----------------------
Python provides many built-in functions.

Examples:
- len()
- type()
- range()
- sum()
