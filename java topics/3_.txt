========================================
MODULE 3: CONTROL STATEMENTS
========================================

3.1 if Statement
----------------
Used to execute a block of code if a condition is true.

Syntax:
if(condition) {
    // code
}

Example:
int a = 10;
if(a > 5) {
    System.out.println("Greater");
}

--------------------------------

3.2 if-else Statement
---------------------
Executes one block if condition is true, otherwise another block.

Syntax:
if(condition) {
    // true block
} else {
    // false block
}

Example:
int a = 5;
if(a % 2 == 0) {
    System.out.println("Even");
} else {
    System.out.println("Odd");
}

--------------------------------

3.3 Nested if
--------------
An if statement inside another if.

Example:
int a = 10;
if(a > 0) {
    if(a % 2 == 0) {
        System.out.println("Positive Even");
    }
}

--------------------------------

3.4 switch Statement
--------------------
Used for multiple conditions.

Syntax:
switch(variable) {
    case value1:
        // code
        break;
    case value2:
        // code
        break;
    default:
        // code
}

Example:
int day = 2;
switch(day) {
    case 1: System.out.println("Mon"); break;
    case 2: System.out.println("Tue"); break;
    default: System.out.println("Invalid");
}

--------------------------------

3.5 for Loop
-------------
Used when number of iterations is known.

Syntax:
for(initialization; condition; update) {
    // code
}

Example:
for(int i = 1; i <= 5; i++) {
    System.out.println(i);
}

--------------------------------

3.6 while Loop
---------------
Executes while condition is true.

Syntax:
while(condition) {
    // code
}

Example:
int i = 1;
while(i <= 5) {
    System.out.println(i);
    i++;
}

--------------------------------

3.7 do-while Loop
-----------------
Executes at least once before checking condition.

Syntax:
do {
    // code
} while(condition);

Example:
int i = 1;
do {
    System.out.println(i);
    i++;
} while(i <= 5);

--------------------------------

3.8 break Statement
-------------------
Used to exit loop or switch immediately.

Example:
for(int i = 1; i <= 5; i++) {
    if(i == 3) break;
    System.out.println(i);
}

--------------------------------

3.9 continue Statement
----------------------
Skips current iteration and continues loop.

Example:
for(int i = 1; i <= 5; i++) {
    if(i == 3) continue;
    System.out.println(i);
}

--------------------------------
