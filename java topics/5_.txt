MODULE 5: ARRAYS
========================================

5.1 One-Dimensional Array
-------------------------
Stores multiple values of same type.

Syntax:
int[] arr = new int[5];

--------------------------------

5.2 Two-Dimensional Array
-------------------------
Matrix (rows and columns).

Example:
int[][] arr = new int[3][3];

--------------------------------

5.3 Jagged Array
----------------
Array with different column sizes.

Example:
int[][] arr = new int[3][];
arr[0] = new int[2];

--------------------------------

5.4 Array Traversal
-------------------
Access elements using loop.

Example:
for(int i = 0; i < arr.length; i++) {
    System.out.println(arr[i]);
}

--------------------------------

5.5 Searching in Array
----------------------
Finding element.

Types:
- Linear Search
- Binary Search

--------------------------------

5.6 Sorting in Array
--------------------
Arranging elements.

Types:
- Bubble Sort
- Selection Sort
- Insertion Sort
